## 🌟 Overview  
**Saikumar’s Shinobi Journal** is a **Naruto-inspired blogging web app** built with **Flask (Python)**.  
It lets shinobi register, log in, and share their ninja stories — all wrapped in a glowing red **Akatsuki-themed** design.  

This project fuses anime aesthetics with clean, modern web development — a true test of coding and chakra control!

---

## 🧩 Features  

### 🥷 User System  
- Register as a new ninja  
- Secure login & logout  
- Personalized profile and post management  

### 📜 Post System  
- Create, edit, and delete posts  
- View all ninja stories in the community feed  
- Chakra-glow effects around posts  

### 🎨 Visuals & Effects  
- Floating **Chibi Naruto** mascot  
- Spinning **Shuriken** animation  
- Chakra-infused glowing text  
- Responsive Akatsuki design
